EthOS NAS Downloader

Send links, magnets and browser downloads to the EthOS NAS Download Manager.

Connection

Base address of your EthOS NAS. Use the LAN address of the machine running the NAS.

Sign in with your NAS account

The password is used once against the NAS login and never stored; the extension keeps the long-lived API key instead.

Copy it from NAS → Settings → Security → API key. Leave this field empty to keep the key that is already stored.

Defaults

Categories are read from the NAS download settings.

Capture

Comma or space separated, without the dot. Used for capture and for ranking page links.
